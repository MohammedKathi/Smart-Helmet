# Smart Helmet Safety System

An IoT-based Smart Helmet Safety System developed to improve rider safety using embedded sensors and automation. The system ensures that the motorcycle ignition starts only when the rider is wearing a helmet.

### Features

* Helmet detection system to prevent bike ignition without wearing the helmet.
* Drowsiness detection using an IR eye-blink sensor that activates a buzzer alert if the rider’s eyes remain closed for more than 2–3 seconds.
* Alcohol detection using an MQ-3 sensor to detect alcohol consumption and automatically cut off the ignition for safety.

### Technologies Used

Arduino Uno, MQ-3 Alcohol Sensor, IR Eye Blink Sensor, Relay Module, Buzzer Module, IoT, and Embedded Systems.

### Skills Demonstrated

Embedded Systems, IoT Development, Sensor Integration, Arduino Programming, Hardware Interfacing, and Safety Automation.
